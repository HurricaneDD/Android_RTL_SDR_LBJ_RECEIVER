## 使用说明
需要的材料和物品：

- RTL2832U FC1003 接收机(带USB插头) 和 天线一根。
- 一根 USB to Type C 的 OTG 连接线，可以将接收器连接到安卓手机上。
- 一台性能尚可的安卓手机，至少安卓5以上。建议在安卓10、骁龙845以上以保证良好的使用体验。

其中接收机可以在闲鱼等平台买到，价值10-40RMB左右。OTG连接线价值5-20RMB左右。

## 可能发生的问题
以下为已经记录到的问题和特性，**如果您在使用中发现问题，欢迎通过Github issue或作者QQ(1727364668)反馈**：

- 基带音频出现明显的尖声，821.2375MHz频率附近出现一个明显的信号尖峰，但并没有显示报文信息。可能是因为信号受干扰严重，无法解析出报文或解析出的报文存在严重的原则性错误。只需等待列车接近，信号加强。**一般在1km左右可收到信号**。
- 同时出现较多列车的信号时，报文可能会互串。例如HXD2B牵引一货列和HXD1D牵引一客列同时接近，报文可能显示客车为HXD2B牵引。
- 首次接到接到信号时，可能只能正确解析数字部分。例如Z167次，首次接到信号可能是167次。这会随着列车接近信号增强而自动修正。
- 可能因为工程车不发送LBJ信号，似乎无法预警工程车辆。
- 可能大部分高铁列车不发送LBJ信号，似乎无法预警高铁列车。
- 部分城际铁路线上运行的高速动车组列车可能不发送LBJ信号，因此无法收到相关预警。在南京站观测到：在沪宁城际旁，没有接收到一列D/G头列车的信号，接收到一列C头列车信号。
- 部分高铁站可能存在刻意或者其他原因引起的信号干扰，在南京南站观测到：820.758到821.718MHz频段内各频率信号都明显加强（RSSI达到-30dB左右，一般情况下底噪为-70到-50dB），但是收不到任何高铁列车信号。
